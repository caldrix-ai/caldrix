# Contributing

Bug reports and questions are welcome as [issues](https://github.com/caldrix-ai/caldrix/issues/new/choose).

This repository is generated from caldrix's private source, and every change made here is overwritten by the next update, so pull requests are not accepted. If you found a mistake in the docs, open an issue and we will fix it at the source.

A useful bug report has:

- the output of `caldrix --version`;
- the output of `caldrix doctor`;
- the exact command you ran;
- what you expected, and what happened instead, with the full output.
